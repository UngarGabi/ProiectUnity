Death by NightTime.

-Un joc inspirat din Dead by Daylight.



Pana acum:

Un script controleaza miscarea si rotatia unui personaj third-person.
Miscarea este relativa la directia camerei, iar modelul vizual se roteste spre directia de mers.
Deplasarea este realizata prin Rigidbody, nu prin transform direct.

S-a creat harta si s-a format terenul folosind Terrain.

S-au adaugat asset-uri utile si s-au facut prefab-uri.

Spawn al inamicilor(sfere rosii) in pozitii random in apropierea player-ului.



Dorim ca review-ul sa fie trimis pe Teams, la Ungar Gabriel.
